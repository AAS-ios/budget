# Мой бюджет

Личное приложение для учёта финансов (Flutter).

## Что умеет

- **Главная:** сколько можно потратить сегодня. Считается так: деньги на счетах минус неоплаченные обязательные платежи до конца месяца, делённые на оставшиеся дни. Там же ближайшие платежи, последние операции и доходы/расходы за месяц.
- **Платежи:** обязательные платежи (коммуналка, связь, страховка…). При оплате выбирается счёт, деньги списываются, дата переносится на следующий период. Просроченные подсвечиваются красным.
- **Статистика:** доходы/расходы за любой месяц, траты по категориям и по приоритету («необходимо / нужно / можно было не брать»).
- **Счета:** карты, наличные, накопления, вклады. Счёт можно редактировать (включая исправление баланса) и удалять. У каждого счёта есть история операций.
- **Операции:** расход / доход / перевод. Операцию можно изменить (нажать) или удалить (смахнуть влево), балансы пересчитываются.
- **Ещё:** категории, источники дохода, резервная копия (через буфер обмена), удаление всех данных.
- Данные сохраняются на телефоне автоматически.

## Запуск на компьютере

```bash
flutter pub get
flutter test          # проверки логики
flutter run -d chrome # посмотреть в браузере
```

> В проекте пока нет папки `web`. Чтобы запускать в браузере, один раз выполните
> `flutter create --platforms=web .` (код в `lib/` не изменится).

## Как поставить на iPhone (если у вас Windows)

Собрать iOS-приложение можно только на Mac, поэтому есть два пути. Оба бесплатные.

### Вариант А. Веб-приложение на экране «Домой» (проще всего, рекомендую)

Приложение открывается в Safari и добавляется иконкой на экран «Домой». Выглядит и работает как обычное приложение, без адресной строки. Обновлять раз в 7 дней не нужно.

1. Зарегистрируйтесь на github.com и создайте **публичный** репозиторий, например `my-budget`.
   Выложен будет только код. Ваши суммы и операции хранятся на телефоне и на GitHub не попадают.
2. Загрузите в репозиторий содержимое этой папки (кроме `build/`, `.dart_tool/`, `.idea/`).
   Удобнее всего через GitHub Desktop, но подойдёт и кнопка «Add file → Upload files» на сайте.
   Папка `.github/workflows` обязательна.
3. В репозитории: **Settings → Pages → Source: GitHub Actions**.
4. Вкладка **Actions**: дождитесь зелёной галочки у сборки (5–10 минут).
   Если её нет, нажмите «Сборка → Run workflow».
5. На iPhone откройте в **Safari** адрес `https://<ваш-логин>.github.io/my-budget/`,
   нажмите «Поделиться» → **«На экран Домой»**.

Обновление: загрузите изменённый код на GitHub, дождитесь сборки и перезапустите приложение на телефоне.

⚠️ Данные хранятся в памяти этого веб-приложения на телефоне. Если удалить иконку с экрана «Домой», они пропадут. Периодически делайте резервную копию: «Ещё → Скопировать резервную копию».

### Вариант Б. Настоящее iOS-приложение через Sideloadly

1. Выполните шаги 1–2 из варианта А. Та же сборка на GitHub делает и файл `.ipa`:
   **Actions →** последняя сборка **→ Artifacts → MyBudget-ipa** (скачается zip, внутри `MyBudget.ipa`).
2. Установите на компьютер **iTunes** (с сайта Apple, не из Microsoft Store) и **Sideloadly** (sideloadly.io).
3. Подключите iPhone кабелем, откройте Sideloadly, перетащите `MyBudget.ipa`, введите свой Apple ID и нажмите Start.
4. На iPhone: **Настройки → Основные → VPN и управление устройством** → доверять своему Apple ID.
   На iOS 16 и новее также включите **Настройки → Конфиденциальность и безопасность → Режим разработчика**.

⚠️ С бесплатным Apple ID приложение перестаёт открываться через **7 дней**, и его нужно переустановить через Sideloadly тем же способом (данные сохраняются, если не удалять приложение). Платный аккаунт разработчика Apple ($99 в год) снимает это ограничение.

### Если есть доступ к Mac

Откройте `ios/Runner.xcworkspace` в Xcode, выберите в Signing & Capabilities свой Apple ID (Team), подключите iPhone и нажмите Run. Ограничение в 7 дней для бесплатного Apple ID действует и здесь.
